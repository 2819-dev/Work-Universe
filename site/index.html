Install in a minute.

No account, no subscription. Download, drag and you're done.

Download

Download QuickSnip and double-click the file in your Downloads folder.

Move to Applications

Drag QuickSnip into your Applications folder, then double-click it to open.

Allow it once

If macOS asks, open System Settings → Privacy & Security and click Open Anyway.

Why the extra step? QuickSnip is distributed independently rather than through the App Store, so macOS asks you to confirm the first time you open it. After that it opens like any other app, and future updates install from inside QuickSnip.
